# References

The `Articles/` folder previously contained ten third-party journal and
conference PDFs that were used as example input documents for `countWord.py`.
They were removed (audit finding F1, 2026-08-28) because redistributing
publisher PDFs in a public repository raises copyright and GitHub ToS concerns.

To try the script, place your own documents (or open-access articles) in a
folder and point `getFileNames(...)` at it (see README → Usage).
